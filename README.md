# 코마 리더

PC의 코마 단어장 로컬 앱이 만든 `.koma.zip`을 열어, 만화를 읽으면서 일본어를 공부하는 오프라인 리더입니다.

- 휴대폰·태블릿 브라우저에서 열고 **홈 화면에 추가**하면 앱처럼 설치됩니다. 설치 후에는 인터넷 없이 동작합니다.
- 압축 안의 PC 번역을 말풍선 위에 덮어 보여 주고, 말풍선을 누르면 PC가 나눠 둔 단어와 뜻으로 공부할 수 있습니다.
- 단어장, 복습(간격 반복), 발음 듣기, 단어장 내보내기/가져오기, Anki용 내보내기.
- 만화와 단어장은 기기 안(IndexedDB)에만 저장됩니다. 이 저장소에는 앱 프로그램만 있습니다.

사용한 라이브러리: [JSZip](https://stuk.github.io/jszip/) (MIT, `vendor/JSZIP-LICENSE.md`)
